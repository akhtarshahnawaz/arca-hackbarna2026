# Official Catalan facilities

These records are **not** hardcoded in the UI and **not** fetched live on each page load. They come from public open-data APIs that do **not** require an API key. `npm run data:refresh` downloads them into `facilities.json` in this folder. The app reads that snapshot (override the path with `ARCA_OFFICIAL_DATA_PATH` if needed — that variable is a file path, not a secret).

Refresh from the project root with `npm run data:refresh` (Python 3, standard library, internet required). The checked-in snapshot covers Bages, the demo incident area. Use `npm run data:refresh -- --all-catalonia` to replace it with all Catalonia, or `--comarca <name>` for another comarca. Full-region imports can take time; the dashboard currently ranks every imported facility. No external requests run during dashboard refresh. Hospital bed counts are joined from the Ministry of Health public Excel download (CNH 2025), not from a keyed API.

Sources: Generalitat SODA school directory `kvmv-ahh4`, enrolments `xvme-26kg`, RESES `ivft-vegh`, equipment `8gmd-gz7i`, municipality reference points `wpyq-we8x`; Ministerio de Sanidad CNH 2025 workbook; IGN CartoCiudad candidates/find. URLs and stable source IDs are retained. School academic years must match. Only enrolment totals are summed; unknown/suppressed counts remain unknown. Enrolments may count registrations rather than distinct people. Places and installed beds are not current occupancy.

Care homes cover residential services for older people. Day centres, disability services, campsites and nationwide registry expansion remain future work. CAP records are classified separately (the source also includes local consulting rooms and services). CNH enrichment matches unique normalized name + municipality, preserves CCN and never uses fuzzy scores. Unmatched hospital capacities remain unknown in `hospitalMatchReview`; the source is not a complete national hospital layer. The importer is pinned to CNH 2025; review its URL/schema when updating editions.

Geocoding accepts a unique portal with matching municipality, postcode and house number. Unresolved addresses fall back to explicitly labelled municipality reference points, or appear in `unlocated`. Those approximate locations are excluded from fire-arrival intersection calculations and stay on watch pending verification. Do not interpret zero reaching runs for such sites as safety. Review `approximateLocations`, `geocodingErrors`, and `hospitalError` after import. Cache stores successful coordinates and retries failed lookups. `--skip-geocoding` explicitly uses approximate locations. New snapshots replace old files atomically only after core imports and validation succeed. CNH/geocoding failures are reported without dropping other facilities.

Capacity is displayed with provenance. Existing class-based evacuation durations remain assumptions; no unsupported people-per-hour model is inferred from capacity. CAP uses a configurable 1-hour demo assumption in `config/evac-times.json`. Fire polygons remain DEMO. Official telephone numbers stay server-side and use the existing decision/approval flow; importing data makes no calls. Demo and OSM seeds retain their provenance and can overlap real facilities; this is not a reconciled census.

Official snapshots contain no OSM enrichment; OSM seeds remain separate. Source licence notices prevail. `fetchedAt` is retrieval time, not the source record update date. Snapshots older than 8 days raise a refresh warning. Run `npm run test:data` and `npm test` for import and app checks.
